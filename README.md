# Browser Agent Kit

Browser automation with policy hooks for governed agents.

![CI](https://github.com/NotPBShaw/browser-agent-kit/actions/workflows/ci.yml/badge.svg)

Python toolkit for scripted browser task execution with step validation.

## Quickstart

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
pytest -q
```
